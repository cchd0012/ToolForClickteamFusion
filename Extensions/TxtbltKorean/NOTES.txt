txtblt.mfx(Text Blitter) 한글 패치 (프로토타입, C++ 도구로 이식 예정)
=====================================================================
dtge 의 'Text Blitter (particle)' 가 한글 문구를 그리도록 txtblt.mfx(8424C67E 판) 모듈 자체를 고친다 (DLL 프록시 아님)

동작
- 앱 코드페이지를 949, 로케일을 1042 로 바꾼다 (청크 0x2246 / 0x2251). 그래야 한글이 ANSI 확장에 CP949 2바이트로 넘어온다
- 레이아웃 함수(0x10008cf0)가 글자 표를 채운 직후 fold_hangul 을 호출해, KS X 1001 한글 음절(앞 B0~C8 + 뒤 A1~FE)을
  반셀 코드 두 개(80~AF, C9~FF 중)로 같은 문자열 안에 바꿔 쓴다. 한 음절 = 두 칸이라 줄 계산/그리기 코드는 그대로이다
- 폰트 이미지(원래 512x224, 16x32 셀) 아래쪽에 번역에 쓰인 음절만 담은 아틀라스를 이어 붙인다 (make_txtblt_atlas.py)
- 폰트 표면은 생성자가 편집 데이터 크기로 만들므로, 높이/폭 인자를 아틀라스 크기로 바꾼다 (atlas_height)
- 글자 표 할당 0x1000 -> 0x2000 (뒤쪽에 문자열 해시/코드->칸 표를 둔다)
- 새 섹션 .kfold 에 후크 코드, 헬퍼, 음절 표(압축 번호)를 넣는다 (재배치 없는 위치 독립 코드)

파일
- txtblt_fold.c : 헬퍼 (fold_hangul, atlas_height)
- build_txtblt_fold.bat <출력 폴더> : 32비트 오브젝트로 컴파일
- make_txtblt_atlas.py : 폰트 이미지 + 한글 ttf + 음절 -> 아틀라스 png + 음절 표 bin
- patch_txtblt.py <원본 mfx> <obj> <표 bin> <셀폭> <출력 mfx> : 모듈에 코드를 심는다
시험에서 확인한 것 (2026-11-02): 공격 10번의 한글 파티클 문구가 정상으로 나오고 속도 저하 없음
알려진 제한: KS X 1001 음절(2350자)만, 문자열 하나에 서로 다른 음절 최대 약 51개 (넘으면 ?)
