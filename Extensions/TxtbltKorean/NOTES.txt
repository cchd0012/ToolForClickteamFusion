txtblt.mfx(Text Blitter) 한글 패치
=================================
dtge 의 'Text Blitter (particle)' 가 한글 문구를 그리도록 txtblt.mfx(8424C67E 판) 모듈 자체를 고친다 (DLL 프록시 아님)

동작
- 앱 코드페이지를 949, 로케일을 1042 로 바꾼다 (청크 0x2246 / 0x2251). 그래야 한글이 ANSI 확장에 CP949 2바이트로 넘어온다
- 레이아웃 함수(0x10008cf0)가 글자 표를 채운 직후 fold_hangul 을 호출해, KS X 1001 한글 음절(앞 B0~C8 + 뒤 A1~FE)을
  반셀 코드 두 개(80~AF, C9~FF 중)로 같은 문자열 안에 바꿔 쓴다. 한 음절 = 두 칸이라 줄 계산/그리기 코드는 그대로이다
- 폰트 이미지(원래 512x224, 16x32 셀) 아래쪽에 번역에 쓰인 음절만 담은 아틀라스를 이어 붙인다 (make_txtblt_atlas.py)
- 폰트 표면은 생성자가 편집 데이터 크기로 만들므로, 높이/폭 인자를 아틀라스 크기로 바꾼다 (atlas_height)
- 글자 표 할당 0x1000 -> 0x2000 (뒤쪽에 문자열 해시/코드->칸 표를 둔다)
- 새 섹션 .kfold 에 후크 코드, 헬퍼, 음절 표(압축 번호)를 넣는다 (재배치 없는 위치 독립 코드)

파일
- txtblt_fold.c : 헬퍼 (fold_hangul, atlas_height)
- build_txtblt_fold.bat <출력 폴더> : 32비트 오브젝트로 컴파일
- make_txtblt_atlas.py : 폰트 이미지 + 한글 ttf + 음절 -> 아틀라스 png + 음절 표 bin
- patch_txtblt.py <원본 mfx> <obj> <표 bin> <셀폭> <출력 mfx> : 모듈에 코드를 심는다
시험에서 확인한 것 (2026-11-02): 공격 10번의 한글 파티클 문구가 정상으로 나오고 속도 저하 없음
알려진 제한: KS X 1001 음절(2350자)만, 문자열 하나에 서로 다른 음절 최대 약 51개 (넘으면 ?)

C++ 도구 사용법 (이식 완료)
- 추출: ToolForClickteamFusion.exe --extract <exe> font blobs image script text module
  (폰트 이미지 PNG 하나, 예: image/000953.png 는 남겨 둔다. 나머지 PNG 는 지우면 교체할 때 그 이미지만 바뀐다)
- 설정 json(glyphConfig 와 같은 파일)에 "txtbltHangul" 블록을 둔다:
    "txtbltHangul": { "module": "modules/0004_8424C67E_txtblt.mfx", "fontImage": "image/000953.png",
                      "objectName": "Text Blitter (particle)", "frames": [14],
                      "font": "binaries/DTM-Mono-RU.ttf", "size": 32, "cellWidth": 16, "cellHeight": 32 }
- 적용: ToolForClickteamFusion.exe --txtblt-limited-hangul <추출 폴더> <설정 json>  이벤트 JSON(script/frame)에서 objectName 의 액션이 받는 문자열을 찾아 text/frameEventText.json 의 번역에서 한글 음절을 모으고,
  폰트 이미지 PNG 를 아틀라스로 덮어쓰며 모듈에 코드를 심는다 (이미 패치된 모듈이면 건너뛴다)
- 교체: ToolForClickteamFusion.exe --replace <exe> font blobs image script text module codepage=949 locale=1042
- 헬퍼(txtblt_fold.c)를 고치면: build_txtblt_fold.bat 로 컴파일 -> make_code_header.py 로 Glyph/TxtbltFoldCode.h 를 다시 만든다
- 자체 시험: Tests/build_txtblt_fold_test.bat <출력 폴더> (32비트, 접기 동작/재진입/코드 부족 등)
- 파이썬 시제품(patch_txtblt.py, make_txtblt_atlas.py)과 C++ 결과가 모듈은 바이트 단위, 아틀라스는 픽셀 단위로 같고,
  만들어진 exe 도 사용자가 게임에서 확인한 시험 exe 와 바이트 단위로 같다
