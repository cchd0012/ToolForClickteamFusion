따라서 직접 만드는게 유일한 방법임


1. 프로젝트 속성 변경

    Visual Studio에서 프로젝트를 엽니다.
    솔루션 탐색기에서 프로젝트를 오른쪽 클릭하고 '속성'을 선택합니다.
    '구성 속성' -> '일반'으로 이동합니다.
    '출력 형식'을 '응용 프로그램(.exe)'에서 'Windows 응용 프로그램(.exe)'로 변경합니다.
    'C/C++' -> '명령줄'에서 추가적인 옵션을 설정할 필요는 없습니다.
	
2. main 함수 수정

	이제 main 함수를 WinMain으로 변경해야 합니다. WinMain은 Windows 애플리케이션의 진입점입니다.	
	
#include <windows.h>

// 윈도우 프로시저
LRESULT CALLBACK WindowProc(HWND hwnd, UINT uMsg, WPARAM wParam, LPARAM lParam) {
    switch (uMsg) {
        case WM_DESTROY:
            PostQuitMessage(0);
            return 0;
    }
    return DefWindowProc(hwnd, uMsg, wParam, lParam);
}

// 메인 함수
int WINAPI WinMain(HINSTANCE hInstance, HINSTANCE, LPSTR, int nShowCmd) {
    // 윈도우 클래스 등록 및 생성
    const char CLASS_NAME[] = "Sample Window Class";

    WNDCLASS wc = {};
    wc.lpfnWndProc = WindowProc;
    wc.hInstance = hInstance;
    wc.lpszClassName = CLASS_NAME;

    RegisterClass(&wc);

    HWND hwnd = CreateWindowEx(
        0, CLASS_NAME, "My Window", WS_OVERLAPPEDWINDOW,
        CW_USEDEFAULT, CW_USEDEFAULT, CW_USEDEFAULT, CW_USEDEFAULT,
        NULL, NULL, hInstance, NULL);

    ShowWindow(hwnd, nShowCmd);

    // 메인 루프
    MSG msg;
    while (GetMessage(&msg, NULL, 0, 0)) {
        TranslateMessage(&msg);
        DispatchMessage(&msg);
    }

    return 0;
}
